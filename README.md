# AgriTech

Repositorio de trabajo del equipo para Proyecto Final de Carrera III.

Cada cambio se entrega en una rama y un pull request. El asunto de los commits debe comenzar con la clave y el título literal de la historia de Jira, por ejemplo `SCRUM-11 HU2 – Identificar la plaga con YOLOv8: validar inferencia`.

La reconstrucción del código se realiza a partir del paquete `AgriTech_Entrega_Semana11.zip`. El paquete contiene el proyecto base, instrucciones por integrante y un respaldo completo del historial previo. No se debe subir el modelo ResNet de 234 MB, datos privados, contraseñas ni archivos de entrenamiento de gran tamaño a GitHub.
