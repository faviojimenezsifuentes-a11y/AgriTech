# AgriTech

Proyecto académico de detección visual de plagas del espárrago mediante YOLO.

La implementación del MVP, los pesos usados para la demostración, las pruebas y las instrucciones de despliegue están en [mvp](mvp/README.md). El sitio de demostración es [esparragos.comextech.es](https://esparragos.comextech.es/).

La carpeta `docs` conserva el avance previo del equipo con un nombre de archivo compatible con Windows.
